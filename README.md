# 구현 기능 목록


###  1. 입력받은 경주 자동차 이름을 Split

+ 입력받은 String을 자동차 이름들로 분할
+ 각각의 자동차 이름이 5자 이하인지, null이 아닌지 검사. 아닐 시 예외 발생

### 2. 몇 번의 이동을 할 것인지 시도 횟수 입력 받기

+ 이동 시도 횟수 값에 대하여 String을 int로 변환
+ 이동 시도 횟수 값의 예외 처리

### 3. 경주 진행도 반복 출력

+ 한 자동차에 대한 전진 조건 체크
+ 한 자동차의 전진 결과 출력
+ 전진을 시도할 횟수만큼 반복

### 4. 최종 우승자 출력

+ 최종 우승이 될 전진 횟수 확인
+ 전진 횟수에 맞는 자동차 이름들 List화
+ 최종 우승자 List를 String으로 변환 후 출력
